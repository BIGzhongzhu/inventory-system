# 内部耗材管理系统 - 本地部署指南

## 一、你需要准备什么

1. **Node.js 20+** — 从 https://nodejs.cn 下载安装（选 LTS 版本）
2. **一个 Supabase 账号** — 免费注册：https://supabase.com
   - 数据库可以用 Supabase 的免费版，本地只跑前端，数据库放云上

> 💡 如果你想数据库也完全跑本地（不联网），可以装本地 PostgreSQL，但推荐用 Supabase 云数据库，省事又稳定。

---

## 二、在 Supabase 创建数据库（约5分钟）

1. 打开 https://supabase.com ，注册账号
2. 点击 **New Project**，填写：
   - 项目名：随便填，比如 "haocai"
   - 数据库密码：设一个自己记得住的密码
   - 区域：选离你近的（新加坡 / 日本都可以）
3. 等待 1-2 分钟，项目创建完成

### 2.1 执行初始化 SQL

1. 项目创建好后，点击左侧 **SQL Editor**
2. 点击 **New query**
3. 打开你下载的包里的 `supabase-init.sql`，复制全部内容
4. 粘贴到 SQL Editor，点击右下角 **Run** 执行
5. 看到 "Success. No rows returned" 就表示成功了

> 如果你要把现有数据搬过去，就执行 `data-backup.sql` 而不是 `supabase-init.sql`

### 2.2 获取三个连接信息

点击左侧 **Settings** → **API**，你会看到：

| 字段名 | 对应的值 | 记下来 |
|--------|----------|--------|
| Project URL | 形如 `https://xxxx.supabase.co` | 记为 URL |
| anon public | 一长串字符 | 记为 anon key |
| service_role secret | 一长串字符，点击 "Reveal" 显示 | 记为 service key |

## 三、本地安装运行

### 3.1 安装 pnpm

打开 CMD 或 PowerShell，输入：

```bash
npm install -g pnpm
```

### 3.2 解压项目代码

把 `inventory-system.zip` 解压到任意目录，比如 `D:\haocai-system`

### 3.3 配置环境变量

在解压后的目录里，新建一个文件叫 `.env.local`（注意前面有个点），内容如下：

```
COZE_SUPABASE_URL=你的Project URL
COZE_SUPABASE_ANON_KEY=你的anon key
COZE_SUPABASE_SERVICE_ROLE_KEY=你的service_role key
```

把等号后面换成你刚才记下来的三个值，比如：

```
COZE_SUPABASE_URL=https://abc123.supabase.co
COZE_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
COZE_SUPABASE_SERVICE_ROLE_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
```

### 3.4 安装依赖

在项目目录下打开 CMD，运行：

```bash
pnpm install
```

等一两分钟，装完会显示绿色的 Progress。

### 3.5 启动系统

```bash
pnpm run dev
```

启动成功后会显示：
```
✓ Ready in xxx ms
  Local:        http://localhost:5000
```

### 3.6 打开访问

浏览器打开 `http://localhost:5000`

- 如果是初始化的新库：账号 `admin`，密码 `88888888`
- 如果是导入数据备份：用你原来的账号密码登录

## 四、设置开机自启（可选）

如果你想每次开机自动运行，可以用以下任一方式：

### 方式 A：放到启动文件夹（最简单）

1. 按 `Win + R`，输入 `shell:startup`，回车
2. 新建一个 `启动系统.bat` 文件，内容：

```batch
@echo off
cd /d D:\haocai-system
pnpm run start
```

> 注意：生产模式要先 `pnpm run build` 一次

### 方式 B：pm2 守护进程（推荐）

```bash
npm install -g pm2
pnpm run build
pm2 start "pnpm run start" --name "haocai"
pm2 save
pm2 startup
```

## 五、常见问题

**Q: 打开页面显示 "数据库尚未初始化"？**
A: 说明你还没去 Supabase 执行 SQL 脚本，按第二步 2.1 操作就行。

**Q: pnpm install 很慢？**
A: 可以设置国内镜像：
```bash
pnpm config set registry https://registry.npmmirror.com
```

**Q: 端口 5000 被占用了？**
A: 在 `.env.local` 里加一行：`PORT=3000`（换成你想要的端口）

**Q: 其他人怎么访问我本地的系统？**
A: 同一局域网内，别人可以用你的电脑 IP + 端口访问，比如 `http://192.168.1.100:5000`

**Q: 想换电脑部署数据怎么办？**
A: 先用 `data-backup.sql` 备份数据，到新电脑的 Supabase 里导入就行。
